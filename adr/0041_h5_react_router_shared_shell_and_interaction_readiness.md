# ADR-0041：H5 官方路由、共享应用壳与交互就绪

- 状态：Accepted
- 日期：2026-10-22
- 前向修订：ADR-0035的国际化实现选择、ADR-0037、ADR-0040；原会话、权限终检、Ticket事实、资源及120KiB预算保持。

## 背景

用户在Android企业微信确认ADR-0040版本清晰回听及转文字功能正常，但识别开头容易漏词；还报告首页冷启首击导航无效、页头尺寸漂移、同秒时间线阶段顺序、英文工单用语／日期、固定欢迎语及快速骨架闪现。

当前源码使用自写Hash导航。实际编译页面已复现首次focus触发entry复核，纯导航CTA共用writeReady门而在首击前失效；保留相同fixture并只预先获得焦点时首击通过。实际录音控制器也已复现清晰录音开始后、企业微信实际起录回执仍pending时过早显示recording；这证明提示时序缺陷，不证明ASR模型或物理双路质量回归。

## 决策

1. 使用官方`react-router`的声明式HashRouter、Routes／Route与公开hooks管理main-content导航；统一共享AppHeader／Shell不随普通页切换卸载。链接UI使用官方`useHref`／`useLinkClickHandler`，激活态使用`useMatch`，不引入不适用本SPA的Framework预取UI，也不自行实现history或匹配算法。保留既有`#/`、`#/report`、`#/reports`、详情、筛选、外部旧入口、返回与替换语义，代码与entry继续并行，温缓存不绕过恢复核验。不得为满足包体数字仅改拆包统计或提高预算。
2. 页面展示、站内导航与写就绪分别控制。已获权展示和纯导航不因后台focus复核而失活；写操作继续在复核中禁用。目标页依然核entry，401／403与成员／组织范围变化立即沿原路径取消、清除、卸载，不展示新范围的旧资料。
3. 三主页面共享56px页头内层高度，Logo沿Workspace统一32px；safe-area、主题边框不变。详情不渲染右侧个人与更多入口及对应弹窗，保留返回、品牌与标题。帮助与个人功能在其原有适用主页面按需加载。
4. 英文集合文案使用My tickets／Recent tickets，报修动作及既有API路径不更名。完整英文日期先日后短月，例如`22, Oct`，可继续附时间；中文、时间-only、业务上海时区和输入守卫保持。欢迎语按上海时间05／12／18时段切换，独立叶状态只安排下一边界，隐藏暂停、恢复校正及卸载清理。
5. Service progress仍按业务时间倒序，仅同一业务秒内明确的Received／Ticket created／In progress三个展示阶段按因果顺序排列，最新在上；同类、未知及其他安全事件不被推断为新状态。原事件、摘要、分页、高水位、迟到语义和数据库不变。
6. Loading挂载160ms后才展示骨架，快速完成不闪出灰块；真实内容就绪立即展示，不为等待一轮shimmer增加最短阻塞。已有同范围可用内容不因后台刷新被骨架覆盖。保留尺寸占位、语义提示及reduced-motion。录音核心按钮使用有限幅度、仅transform／opacity的呼吸提示，准备／禁用停止动效，避免布局与点击目标移动。
7. 清晰音频继续立即采集，辅助企业微信录音实际ACK之前显示“正在准备”，不提前邀请说话；辅助准备沿现有5000ms有界预算，失败／超时明确降级为清晰采集并给非阻断提示。超时或取消不伪造设备实际settle；迟到SDK不得起录、迟到原生ACK实际停止并保留原单槽屏障。纯网页能力无需等待辅助，最短2000ms仍按清晰采集的原始单调时钟。没有新增ASR服务、模型参数、费用、持久模式或上传第二份原生材料。

8. 读取与动作代码按真实使用时机划分，写操作、媒体上传及SDK签名在动作触发时加载；首屏所需读取解码仍包含在首屏预算。传输、ApiError及认证代际只有一个实例，加载等待后检查原代际与取消信号。仅可证明尚未派发请求的本地代码加载失败可作为安全重试错误；真实POST／回执未知仍沿原UUID恢复，不能按服务端错误码伪称“未发送”。

实验构建曾针对官方生产包的组件构造与调试名称组合增加局部消除适配；该适配及其正负控制留存于试验原件。最终构建采用官方生产入口与Lingui预编译目录，完整闭包继续按原预算验收。

9. React国际化能力保持，执行引擎前向采用官方Lingui core／React binding与预编译消息目录。现有五个namespace、简体中文／English全文、插值、延迟资源、偏好归一化和语言变化订阅逐项验证；不引入运行时消息编译器、eval或第二套翻译引擎。主双语目录与React binding的独立生产对照显示约13KiB gzip空间，足以继续核对原首屏预算；该独立数字不当作整页PASS。译文由官方编译器在开发／构建侧处理，目录与配置纳入输入身份，未编译、缺项或占位符不等价必须失败。若真实完整闭包允许，删除已不需要的临时构建适配，保留试验原件。

## 验证与回退

保留首击自然反例、焦点唯一控制、原生ACK延迟反例和每个候选的失败。覆盖官方路由首击／返回／直达／筛选／恢复／撤权、统一header几何、快慢骨架、两主题／语言／320与390px、同秒事件六排列、05／12／18欢迎语、2000ms及辅助延迟／超时／取消。生产Profiler及完整首屏预算按本次候选核对；合成SDK和浏览器验证不能证明实机ASR准确率。

无数据库或持久Feature Flag变更。回退切回已验证制品，保留配置、媒体、历史事实与原件。实际状态以本轮Issue、编译身份、CI及验收回执为准，不推进full/certify、实发或Gate。

Windows测试宿主编译遇到CS1619时，可显式传入已验证的preparedHelper；工具复核当前C#原字节、来源路径链和EXE哈希，复制到新任务目录后仍走完整原Job。C#、2CPU／4GiB限额、解码和清理规则不变。未提供时仍沿原编译路径，校验失败不静默降级；宿主复用不等于页面或业务验收通过。
