# ADR-0039: H5 本人展示资料的官方只读来源

Status: Accepted for the user-authorized H5 profile repair on 2026-10-22; no Gate advancement.

## Context

历史 H04／H04B [能力矩阵](../evidence/g0-005-active-push-matrix.md)已验证代开发应用的 `user/get` 姓名和 `department/get` 部门名称。新版首页却仅查第三方本地目录，未命中时永久显示通用称呼。当前 H5 的 `APP_OPEN_USERID` 不能作为第三方目录查询 UID；缺少可信绑定时不猜测对应关系。

## Decision

- 在现有 H5 显式开关下新增同源、`no-store` 的本人展示资料 GET，页面关键 entry 完成后按需读取。仅补充缺少的姓名、主部门显示名称，不要求手机号、头像等敏感字段授权，不新增人员主档或组织同步。
- 复用同一个当前成员核验 scheduler：本次 `user/get` 核验后读取其声明的主部门（缺少主部门时选首个部门）。最多一次 `department/get`，完整工作占 BASE 单槽和既有 32 项队列，总 5 秒含排队；取消和超时不得提前释放尚未 settle 的实际槽。普通 entry 继续只核验成员，不等待部门网络。
- 核验结果只存于当前 HTTP 请求的 WeakMap。部门名称缺失或查询暂不可用不得变成“没有科室权限”的判断；明确成员拒绝仍为 401／403，成员核验暂不可用仍为 503。等待后、返回前继续检查 Cookie、当前会话和同一成员范围。
- 展示 DTO 只有版本、会话恢复范围、姓名和部门名称。不返回原始成员／部门 ID、凭据或 Provider 错误。浏览器只在已确认的同成员、同组织修订、同认证代次内存缓存中使用，30 秒新鲜度、2 分钟非活动回收；取消传至 fetch，401／403 清除受保护状态。
- 展示资料不改变 `can_view_department`、组织关系修订、Reporter HMAC、既有绑定、通知收件人或历史资料快照；科室工单 READ 继续使用本地已核验关系及原终检。

## Verification and rollback

合成测试覆盖无本地目录时本人显示、错误身份拒绝、部门缺失／暂不可用、队列取消／超时、等待时注销／换 Cookie，以及旧成员响应不得进入新范围。原始历史矩阵及失败记录保持。无数据库迁移、业务写入、真实发送或新常驻任务。关闭 H5 或回退页面即可停止新展示读取，原 READ、媒体与事实保留；实机展示另记 `NOT_RUN`，不得由合成结果替代。
