# ADR-0037：H5 前台恢复与局部导航

状态：Accepted for implementation，依据用户于 2026-10-21 的真机反馈及修复授权。真实设备复验单独记账。

## 认证寿命与恢复

启用新版 H5 时，成员 OAuth 登录采用 8 小时空闲期、24 小时绝对上限；旧的非 H5 OAuth 宿主保留 15 分钟合同。浏览器绑定与 Cookie 同步覆盖相应期限。OAuth state/code 的 5 分钟、Provider 的 5 秒和请求内资格凭据预算不变。

F 装配在创建 OAuth 时显式选择策略；独立 M 装配在 H5 初始化时、任何凭据发放前启用同一策略。首次凭据发放后禁止由旧模式升级，即使随后 Map 已过期清空也不能绕过；已经启用 H5 的重复装配为幂等操作。

H5 entry 在原当前成员核验、查询及等待后终检全部成功后，延长仍有效的本地会话；不旋转 SID、CSRF 或恢复范围。续期不得复活已过期、已退出、被替换或浏览器绑定不匹配的会话。绝对到期或进程重启后，使用官方 `snsapi_base` 新 state/code 静默 OAuth，返回当前受限站内页面；没有 H5 refresh_token，不套用小程序登录。

401 与 403 分开：401 允许单次自动静默认证；403 清除受保护缓存和媒体，显示权限提示，不自动换身份重试。网络错误与 503 保留重试能力，不伪装为退出。新认证返回标记抑制重定向循环；失败提供主动重连入口。H5 callback 失败清洁返回带标记的首页应用壳，不回显 code/state，不签发会话；entry 再核验且不能自动重复跳转。OAuth 目标由服务端白名单校验，不能接受外部 URL、协议相对 URL、凭据或任意页面路径。

存在草稿或进行中／UNKNOWN 命令时，不自动执行会销毁文档的 OAuth 跳转，不自动重放业务 POST。交互提示明确重新连接的影响，主动确认与每次跳转前再检查栅栏。认证失败后仍清除旧读取数据；草稿、媒体和凭据不写入浏览器持久缓存。

H5 HTML 是不含成员数据的公开应用壳；业务 entry 承担每次当前成员核验。初次进入和 OAuth 返回可显示应用内双语、随主题变化的认证状态。旧页面及禁用 H5 的宿主继续原处理。

## 页面与缓存

保持当前 Vite SPA 和 Hash 路由。30 秒内返回已核验、同恢复范围与组织修订、未失效且数据仍完整的页面，直接复用内存 Query 缓存。页面代码继续懒加载；不因导航重新载入文档。访问记录有界，不持久化数据，也不挂载所有隐藏页面。

前台恢复、手动刷新和写后同步始终经过原 entry 复核；恢复期间立即关闭写操作。范围／修订变化、401／403、请求取消及写后失效不得被温缓存绕过。快速切换保留取消与 generation 栅栏，旧响应不得回填。

应用壳和底部导航保持稳定，首次加载只替换主内容。温页面在 React 绘制前同步选择缓存，避免 effect 导航前闪现整页骨架。加载状态使用轻量 CSS 动效、屏幕阅读器状态和 reduced-motion 规则；无需新增动画库。沿八屏浅深色原型，不修改用户原件。

## 验证与边界

覆盖 16 分钟恢复、滑动／绝对边界、续期等待后撤权／退出、403、重启后 OAuth、返回路径与循环抑制；覆盖温导航、缓存失效、前台强制复核、快速取消和文档导航计数。保留原 120 KiB gzip、权限终检和资源预算。模拟验证不替代 iOS／Android 企业微信实机。
