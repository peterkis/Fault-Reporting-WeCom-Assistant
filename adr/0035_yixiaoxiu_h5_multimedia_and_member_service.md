# ADR-0035：医小修 H5 多媒体与成员服务

状态：Accepted for local implementation，依据用户于 2026-10-20 确认的重做方案及执行授权。不是现场写库、真实发送、部署或 Gate 批准。

## 决策

新版 H5 使用 Vite、strict TypeScript、React、React Router、TanStack Query、shadcn/ui、Tailwind CSS 和 react-i18next。视觉来源为 Stitch 项目 `1016264531564507497` 的八个浅色／深色移动端页面；本地用户原型保留。新源码、依赖和制品进入原构建清单，不创建第二发布平台。

同源成员 Cookie、CSRF、当前应用可见成员、只读 profile、幂等 UUID、恢复范围和等待后终检继续生效。沿原命令／查询 Port、Web Request、Intake 与 Unified Ticket Core 扩展。V1 合同保留闭合；V2 明确声明故障或需联系意图，允许文字为空且使用媒体材料。联系请求可不带材料。受理不等待转文字、人员补全或 AI 分类；明确故障通过原 Core 建立唯一最小 Ticket。

浏览器可使用官方 `@wecom/jssdk` 的受限设备能力（录音、图片、辅助转文字、已核验目标的原生联系），签名和临时素材获取只在服务端完成。此设备桥不包含 Bot Node SDK、主动投递、业务写库或 Ticket 状态所有权。该窄设备例外前向说明开发边界中的浏览器 SDK 禁止项；服务端凭据不得传至浏览器。

Web 媒体是独立来源支路，不伪造 Bot Inbox／Message／Conversation Session。上传会话和材料绑定当前原成员、企业、应用与用途；绑定原 Web Request／Intake 后，本人和当前获权工作人员方可读取。材料私有加密保存、校验大小与格式、按原 Intake 截止失效；旧 Bot 附件授权不放宽。辅助原生转文字失败不阻断受理，本期没有图片 OCR 或 AI 自动派单。

催单是本轮追加事实，不直接改变优先级、状态或责任；当前获权管理端显示标识和站内提醒，不新增企业微信主动消息。评价绑定真实工作人员完工轮次，不再次关闭；仍未解决沿原反馈重开同 Ticket。公开进度与预计完成时间由获权工作人员明确提交，内部备注保持隔离。

同科室仅共享汇总、编号、服务类别、状态和明确公开进度，不共享报修正文、媒体、人员电话。组织关系须有真实已核验且有效的来源；开放 ID、Bot 原始 UID 和第三方目录 UID 不可猜测互换。复用现有 Provider／目录投影补全人员资料，缺失不阻断报修，不为 H5 新建全员同步或人员主档。

中文语言统一简体中文，其他语言统一 English。主题按企业微信 UA 和系统媒体偏好自动选择。没有可靠来源的床位、设备健康、值班状态、自动派单、固定响应时限不作为真实事实展示。

## 默认上限与关闭

每单语音 1 段／60 秒／5 MiB，图片最多 6 张／每张 10 MiB，视频 1 段／60 秒／20 MiB，总材料 40 MiB。未绑定材料最多 24 小时；已绑定材料不得超过 Intake 保留截止。转码单并发且有界，不新增常驻服务。催单间隔 10 分钟；每完工轮次评价一次，1–5 星，可选短评 200 字。草稿和媒体不持久保存在浏览器。

新增持久开关默认 false。关闭新增写能力后保留原获权读取与原用途回执核对。SQL 仅新增前向迁移，旧迁移、历史 Evidence、通知收件绑定和默认 Sender 保持原合同。

## 验证

用新建合成隔离库及模拟外部能力验证媒体／联系建单、幂等和 UNKNOWN 恢复、跨成员／科室隔离、完工评价与重开、催单和管理端消费。八个设计状态进行同视口视觉比较；语言、主题和录音失败单独验证。实机、实际收件和生产材料处理不得由模拟结果替代。
