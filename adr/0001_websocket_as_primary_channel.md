# ADR-0001：WebSocket 作为企业微信主接入通道

- 状态：Accepted
- 日期：2026-08-20

## 背景

用户已创建企业微信智能机器人并配置 API 和权限。官方 Node.js SDK 提供 WebSocket 长连接、认证、心跳、重连、消息、卡片和媒体能力。

## 决策

采用院内服务器主动发起 WSS 出站连接作为主方案。

公网 HTTP 回调不作为默认架构，仅在实际租户或网络条件要求时另行评估。

## 原因

- 减少公网入站暴露面；
- 避免回调网关和公网域名依赖；
- 官方 SDK 已封装连接生命周期；
- 更符合医院数据和网络边界。

## 后果

- 必须执行 Gate 0；
- 需要连接健康、重连和单活；
- 出站 WSS 需网络放行；
- SDK 必须通过 Adapter 隔离。
