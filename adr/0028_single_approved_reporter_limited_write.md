# ADR-0028：限定写运行支持单名获批 Reporter

- 状态：Accepted
- 日期：2026-10-06

SS011 的 Reporter 白名单允许且仅允许 `['A']` 或 `['A','B']`，实际 userid 数量必须与 alias 数量一致；单名 Reporter 不改变两个不同且有效的获批内部 principal、数据库身份、窗口、配额和批准作用域校验。userid、人数、配置、候选或窗口等绑定输入变化使旧批准失效，原双成员模板仍为未授权模板，真实发送及父 P2-G2 live 继续禁止。

本次只实现和隔离验证上述合同兼容；受控源码变化后须按 ADR-0027 取得新候选技术认证及实际批准才可运行，停止或关闭沿用现有入口，撤销使用后继补丁或独立 revert PR，不删除历史证据、状态或业务事实。
