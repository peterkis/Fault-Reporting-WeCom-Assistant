# ADR-0008：Gate 0 稳定性退出时长为 4小时30分钟

- 状态：Accepted
- 日期：2026-08-27

## 背景

Gate 0 要在本机 Windows 环境验证企业微信智能机器人长连接的稳定性、重连、资源行为和消息重放观察。原执行基线把稳定运行门槛设为 24 小时，但当前网络环境无法提供稳定的 24 小时连续测试窗口。

## 决策

Gate 0 的稳定运行退出条件统一调整为：

```text
连续运行4小时30分钟（16,200,000 ms）
```

该时段必须是独立的最终连续浸泡：完成认证、持续采样、正常结束，且不得混入人为断网、DNS 故障、进程重启或网络抖动演练。

## 不变约束

- G0-007 的断网恢复、DNS、进程重启、网络抖动和消息重放观察仍须逐项完成；
- 仍须完成能力矩阵和 SDK/连接策略 ADR 冻结，方可结束 Gate 0；
- Gate 0 只做企业微信技术验证，不建设 Pilot Ticket Core、不接入 Hospital Tickets；
- Phase 1 仍使用 Pilot Ticket Core，Phase 3 才通过 Ticket Adapter 融合 Hospital Tickets。

## 后果

- 运行时默认浸泡时长、测试任务、验收计划和架构状态统一使用4小时30分钟；
- 已完成的 `68e1b63ba935` 实测满足本 ADR 的稳定运行时长项，但不代表 G0-007 或 Gate 0 整体完成；
- 历史 24 小时启动记录保留为证据，不作重写。
