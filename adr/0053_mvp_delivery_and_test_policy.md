# ADR-0053：人工首版交付与测试执行策略

- 状态：ACCEPTED_ON_AUTHORIZED_MERGE；本 PR 合并后作为前向研发规则，不构成部署或 Gate 批准。
- 日期：2026-11-03
- 入口：[实施与首版验收](../plans/mvp-release-simplification/README.md)、[验证规则](../docs/agents/validation.md)。

人工首版围绕“报修进入 → 信息科查看 → 人工领取/派工 → 记录处理 → 完工 → 本人查看结果 → 必要通知及异常人工处理”。完整 P2/P3 路线图继续用于阶段规划；历史任务编号、selection 和验收记录用于追溯，不自动成为当前开发或人工首版上线的前置。已稳定实现的增强功能保留，本决策不修改运行配置。

普通 PR 先声明影响，再按真实 base/head 差异选择现有检查。路径策略只引用 `test-routing.json` 中的 selection；宿主、flags、超时、隔离、库存保护与制品一致性沿用原工具。未知生产路径使用较宽的当前首版集合；无效 base、未知 profile、缺失入口、应执行而为空或意外跳过都失败。应用构建仍统一执行一次，不引入增量编译平台。

测试的交互步骤和布局前提可以随产品更新；仍有效的权限、幂等、隐私和恢复断言必须保留或先有替代覆盖。测试分为当前必需、按需扩展、历史专用、后续可物理移除；首批历史专用理由记在同一策略文件。分类不掩盖本次引入的失败，不以 skip、放宽断言或改报告换取通过。物理删除逐项核对风险替代、路由、别名及历史消费者，本 PR 保留注册库存保护。

继续保留单一 Ticket 事实源、当前身份和对象权限、幂等、事务与并发冲突、内部/外部内容隔离、UNKNOWN 核对与原 UUID 恢复、数据库迁移安全、输入/资源上限、TypeScript strict、运行时守卫、发布制品追溯及用户/其他任务资源保护。完整草稿体验可以延期，已提交命令的恢复不能延期。

PR 检查、按风险扩展回归、人工首版候选验收、历史复现分别报告。历史证据保留原日期、对象、FAIL/SKIP/NOT_RUN，不反向修改或声称覆盖新候选；full/certify、ADR-0026/0027/0045 的具名认证合同保持原含义。按影响适用的交付取代逐任务十项套表；纯记录后继不自动重建业务候选或完整复审。扩大验证须写明风险、覆盖缺口与停止条件；适用检查通过且缺口关闭即停止。本次缺陷本次修，范围外问题另记。

本决策前向替代研发导航中“普通 PR 固定活动 selection”和“每任务十项必填”的默认要求，不改写其历史执行记录，不改变 `plans/current_phase.json`、数据库、依赖、业务合同或具名生产授权。撤回通过后继修补或独立 revert PR；历史证据保持。
