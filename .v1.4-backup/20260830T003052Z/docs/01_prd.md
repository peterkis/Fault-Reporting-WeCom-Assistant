
# PRD V1.2 摘要

> 唯一架构边界：Phase 1 使用公网 Pilot Ticket Core；Phase 3 才通过 Ticket Adapter 融合 Hospital Tickets。

## 产品目标

建设医院信息故障智能报修助手。

目标：
1. 临床报修即时反馈。
2. 故障处理全过程留痕。
3. 状态透明。
4. 建立信息服务数据资产。

## 用户

临床医生护士：
企业微信报修。

工程师：
移动端接单处理。

管理员：
分诊、统计、运营。

## 非目标

一期不做：
- 电话接入
- IT资产管理
- 自动执行运维命令
- 全院群无感监听
- 多医院租户
- Phase 1 直接接入医院 Tickets
