# Phase 2 任务明细：AI 增强

所有增强均运行在 Pilot Ticket Core 之外的异步链路，不得成为建单或通知门槛。

## P2-001 私有媒体存储、扫描与留存

- 状态：TODO
- 依赖：P1-012
- 输入：Gate 0 媒体能力、安全与留存策略。
- 输出：下载、解密、MIME/Magic、恶意内容扫描、私有存储和删除机制。
- 测试：非法域、超大文件、伪造 MIME、下载失败、删除失败和访问越权。
- 验收：媒体失败不影响文字建单；原图不进入公开日志或公开桶。

## P2-002 OCR 服务与错误代码提取

- 状态：TODO
- 依赖：P2-001
- 输入：受控媒体、脱敏测试集和 OCR 资源约束。
- 输出：异步 OCR、后处理、错误代码提取和版本审计。
- 测试：低清、倾斜、中英混合、超时、服务停止和敏感字段。
- 验收：OCR 失败可降级；不会捏造或覆盖用户原文。

## P2-003 系统目录与确定性规则

- 状态：TODO
- 依赖：P1-012
- 输入：系统目录、别名、错误码、位置和临床关键规则。
- 输出：版本化目录、规则引擎、证据来源和冲突处理。
- 测试：否定词、多系统冲突、未知位置、临床硬规则和版本回归。
- 验收：规则结果可解释；未知值不被自动猜测。

## P2-004 AI Triage 契约与 Provider Adapter

- 状态：TODO
- 依赖：P2-003
- 输入：AI JSON Schema、安全边界和候选本地 Provider。
- 输出：Provider Adapter、超时/熔断、严格 Schema 和模型/Prompt版本记录。
- 测试：非法JSON、超时、模型不可用、Prompt注入和未知枚举。
- 验收：AI 只返回建议，无数据库写权限或工具调用。

## P2-005 AI 异步影子编排

- 状态：TODO
- 依赖：P2-002, P2-004
- 输入：Intake、OCR脱敏文本、规则和AI契约。
- 输出：异步任务、AIDecision追加记录、降级告警和影子结果页面。
- 测试：AI关闭、排队、重复任务、模型切换和核心链路负载隔离。
- 验收：AI停止时 Phase 1 行为不变；AI结果不直接路由或改票。
