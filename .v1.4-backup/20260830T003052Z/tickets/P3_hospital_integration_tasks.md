# Phase 3 任务明细：医院融合

固定路径：Pilot Ticket Core → Ticket Adapter → Hospital Tickets。完成切换后 Hospital Tickets 是唯一长期事实源。

- 状态：TODO
- 依赖：P2-010
- 输入：Hospital Tickets、SSO、组织、附件、通知和权限的真实接口资料。
- 输出：能力矩阵、字段/状态差异、网络边界、缺口和阻断问题。
- 测试：测试环境只读探测、契约样例校验和权限失败路径。
- 验收：不以旧文档假设替代医院真实契约。

- 输出：权威方向、状态所有权、同步方向、冲突处理、切换与回滚 ADR。
