第一层，视图页签 + 显示方式：
- 左侧是下划线视图页签，顺序为 `全部 N` · `我负责 N` · `与我有关` · `已超时 N` · `今日完成 N`。文字 14px；选中项为 `--text-primary` + 600 字重 + 底部 2px `--text-primary` 下划线，未选中为次级灰；页签间距 24px，高 40px；整行底部 1px `--border-hair`。
  - 「待受理」不做页签，因为待受理列的列头已显示数量。
  - 每个页签对应已有视图或筛选：全部 = 原「团队工作」，与我有关 = 原「与我有关」，我负责 / 已超时 / 今日完成 = 卡 10 概况卡片已实现的筛选。不新增接口和筛选逻辑。

### 卡 18 · 抽屉收尾

**1. 时间线按记录类型上色（P1-1）**
- 问题：`drawer-v21.css` 中 `.detail-record[data-audience=INTERNAL] .record-text` 把所有内部可见记录都画成黄色气泡，状态变化也被染黄。
- 修改：在记录上新增 `data-record-kind`，取值 `status | note | report | event`。判定在前端完成：`old_status` 或 `new_status` 不为空 → `status`；有正文且 `audience` 为 INTERNAL 或 EXTERNAL → `note`；`audience=REPORT` → `report`；其余 → `event`。
- 样式：
  - `status`：一行，「姓名 + 动作 + ●旧状态 → ●新状态」，次级灰文字，不加气泡和背景，状态圆点用阶段色。
  - `note` 且 INTERNAL：浅黄气泡 + 锁图标 +「内部」。
  - `note` 且 EXTERNAL：浅灰气泡 +「已发给报修人」。
  - `report`：浅灰气泡。
  - `event`：一行次级灰文字。
- 黄色选择器改为 `[data-record-kind=note][data-audience=INTERNAL]`。补浏览器断言：状态变化记录不带黄色背景。

**2. 下一步文案按查看者视角生成（P1-4）**
- 位置：`WorkbenchDetail.tsx` 的 `nextSummary`。
- 新增参数：当前 principal 是否为处理人。按「状态 × 是否本人」组织文案，例如：
  - IN_PROGRESS + 本人：「你正在处理 · 故障排除后登记完工」
  - IN_PROGRESS + 他人：「林舟正在处理 · 需要时可接管」
  - ACCEPTED + 本人：「你已领取，尚未开始」；+ 他人：「林舟已领取，尚未开始」
  - NEW / QUEUED：「已等待 N，尚无人领取」
- 规则：文案描述的动作必须和主按钮一致。主按钮仍只根据 `allowed_actions` 决定，本卡不改按钮逻辑。补单测覆盖每个状态的本人 / 他人两种情况。

**3. 时间格式统一（P2-5）**
- 抽屉内所有时间：当年为「MM-DD HH:mm」，跨年为「YYYY-MM-DD HH:mm」，不显示秒；用 `<time>` 的 `title` 显示含秒的完整北京时间。抽成一个函数（例如 `formatBeijingShort`），放在 `src/design/` 下。

**4. 下划线页签（P2-6）**

**5. 错误态（P2-7）**
