# Agent 代码审查 Prompt

```text
请审查当前变更是否符合“医院信息故障智能报修助手”规格。

必须逐项检查：

1. 消息是否在回复前可靠持久化；
2. provider + msg_id是否具备数据库唯一约束和并发测试；
3. AI/OCR失败是否影响建单；
4. 是否绕过现有Tickets直接写工单核心；
5. 状态变更是否通过Action API；
6. ticket_event和notification_outbox是否同事务；
7. 是否存在群内敏感信息泄漏；
8. 是否区分内部备注和外部说明；
9. 是否把申报人科室错误当作故障发生科室；
10. 是否仅凭类别/时间合并；
11. 是否处理卡片重复点击和version冲突；
12. 是否在日志输出Secret、原始患者文本、aeskey或媒体URL；
13. 是否有超时、重试、死信和幂等；
14. 是否新增未批准基础设施；
15. 是否具备单元、Contract、集成和降级测试。

输出：
- 阻断问题；
- 高风险问题；
- 中低风险问题；
- 测试缺口；
- 合规缺口；
- 是否允许合并；
- 必须修改的最小清单。

不要只做风格审查。
```
