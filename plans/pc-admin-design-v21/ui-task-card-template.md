# PC 管理端 UI 任务卡模板

适用后续每张 UI 卡。仓库未找到既有专用 UI 卡或 PR 模板，本模板在卡 35B 新增；不改写历史卡片验收记录。

## 范围与约束

- 目标、相关画板、业务合同与改动范围：
- 排除范围、前置依赖与停止条件：
- 复用 design/components，颜色、间距、时长使用 token；合成数据标「（合成）」。

## 验收与 PR 描述

- 改动清单、删除清单：
- 逐条验收 PASS / FAIL / NOT_RUN 及证据：
- typecheck、eslint、stylelint、build、文案检查、相关浏览器测试实际结果：
- 截图清单及运行环境（OS、Chrome 版本、DPR）：
- **每张 UI 卡 PR 必附 `visual:compare` 摘要**：命令、退出码、报告路径、变化画面列表、每屏是否预期及原因；缺少基线须如实报告，不得写成无变化。
- 基线更新只能由产品负责人确认有意的设计变更或新增画面后，在交互终端逐次批准；Agent 不批准。不同平台单独建基线。
- Open questions / 未执行项 / 限制 / 回退：

详细操作见 [截图回归约定](../../docs/ui/visual-regression.md)。
