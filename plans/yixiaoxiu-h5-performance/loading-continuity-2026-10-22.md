## 候选与验证

重构沿既有 React Router、TanStack Query 与 React 延迟展示，区分目标路由和当前展示路由。进度条延迟 200ms，显示至少 300ms 后结束；内容不等待进度条。保留新鲜缓存 30 秒规则，并允许 2 分钟内的完整旧缓存在 entry 复核期间先展示。默认关闭的持久开关不变，无数据库变更、业务 POST 或真实 Provider 调用。

首次正常企业微信认证由应用入口静默发起一次同源登录，不先挂载认证失败页面；草稿／UNKNOWN 和认证返回循环保护继续生效。外部浏览器只显示打开指引，UA 不承担服务端授权。401／403、范围或组织修订变化清空旧展示，写门在切换／后台核验期间关闭。

实现期间另保留后台详情 entry 更新组织修订但无导航任务的 RED：旧展示已清除，却未重新核验当前页。修补后任何认证代际变化都重读当前目标。只读审查还确认官方 Router 接受的尾斜杠路径被登录白名单拒绝，现统一生成规范 return path；带游标缓存的手动分页会绕过 Query enabled，现按钮和点击处理都核对当前就绪状态。原白名单和服务端授权不扩大。
