## 配置与兼容边界

`TS_MIGRATION_TEST_SOURCE_ROOT` / `TS_MIGRATION_TEST_RUNTIME_ROOT` 只用于 tests/helpers/migration-roots.mjs。
该 helper 校验真实 Git root、实际 helper 所在目录和固定 `.build/runtime`，只暴露源码文本路径；生产 src/scripts 不读取这些变量。
这是一个按路径登记的测试兼容 MJS，retire_stage=T11，禁止生产导入；它不是新增生产 JS 或工具目录豁免。
旧 npm 测试别名的选集/Node 参数不可由当前 registry 单方面弱化，必须匹配已合并 T01 原命令。仅测试的 `.env.pilot` 参数被显式隔离环境替代。
G2 原业务 Gate 证据格式不被重写；新 runner 的记录属于 SYNTHETIC_MIGRATION，不是重新批准的 P2-G2 全量 readiness 证据。
