# 人工工作台任务拆分草案

本文件是已批准的发布前拆分记录。43票已发布并核对，实际编号/阻塞关系见[正式任务清单](tickets.md)。将已确认的17个工作包拆成43票；保留原业务决定，仅细化可独立演示、在一个新上下文中完成的交付。01是必要合同/基线前置，其余功能票包含各自所需Schema、HTTP、界面和验证；43验证完整隔离闭环。

任务去向已确认为GitHub Issues，默认triage词汇及43票拆分已确认。ready-for-agent表示描述可执行，不表示所有票没有阻塞，也不授权现场运行。下文保留当时对候选跟踪器的说明及逐票预览，实际状态以正式导航和GitHub为准。

## 拆分依据

- 每票对应具体可演示的人员行为，合同和必要Schema在本票同步，不设全后端完成后才接全前端的大横向票。
- 从原工作包中移除不必要的整包依赖：已有附件不等待完工；来源群显示名称不阻塞通知路由；Bot私聊不等待H5；普通回复的待跟进判断依赖其Delivery结果，不等待全部工单里程碑通知。
- 通用原子事务/命令边界在最先用到它的窄行为中实现，后续复用；不借清单做宽重构或改变已确认状态机。
- 43只直接阻塞于依赖图叶节点，经传递依赖覆盖01–42，不列无用的重复边。
- 本次不执行任何业务票；现有Feature Flag默认false、资源上限、旧Evidence和Gate停止线继续生效。
