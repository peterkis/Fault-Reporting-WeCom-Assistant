## 安全、资源和关闭

活动 principal／对象可读在 receipt 查找前复核；新写入另查当前动作许可和版本。COMMITTED／FAILED 的原 receipt 是只读核对，不声称再次执行当前写动作检查。失去单独写权仍可核对获权可读 receipt；失去对象或活动身份拒绝。Header/body UUID、If-Match、Cookie CSRF／Origin、闭合字段和内部受众均在真实 HTTP 验证。

UNKNOWN 保留不可变原 UUID／原版本／原 payload，禁止隐式重发或换 ID；200 不可信正文也不能被当作成功。可信 401／403／404 即使正文不可信仍清相关授权；200／不确定 5xx／网络异常保持未知。Query／mutation 都取消并清同对象缓存，卸载 abort 自有 POST；abort 不证明未提交。原命令／输入仅在组件内存，T03 才扩持久恢复；不把业务事实放入 Zustand。

新宿主选项 `workbenchInternalNotesEnabled=false`，bootstrap 的 `internal_notes_enabled` 不是对象权限。关闭该选项即拒绝新入口／隐藏表单，原默认 Flag、旧入口、Ticket／事件／receipt 保留；代码关闭用后继修补或独立 revert，不删除事实。备注≤2000、W body≤32KiB、单表单 in-flight1，未加轮询／重试／进程。复用 pool4／同机预算8、SSE32、单 App／Worker／Gateway、concurrency1。合成 fixture 随机库独占并 finally stop server／浏览器和 drop 自有库；不停止用户 PG 或启动第二个 cluster。
