## 固定行为

| 情况 | 群 Bot 回应 |
| --- | --- |
| 明确故障且受理成功 | 收到啦～小修记下了，工程师马上联系您，稍等哦 🛠️ |
| 无法判断 | @用户名称 这条小修没完全看懂😅 麻烦您私信我一下啦，回复两句就能安排～ |
| 单纯致谢 | 不用客气噢，这是小修应该做的啦~ |
| 其他明确非故障 | 静默 |

无核验姓名时省略称呼。不要求 Bot 原生 @。人工接管后只有固定致谢例外。混合故障优先，补充和回调重放不重复首报确认。

个人模板仅首次实际接单／开始处理及工作人员完工，每轮各一次。群来源另在完工时按原 botId + groupId 的 Webhook 发送：`@用户 工单#{完整业务编号}小修已完成，麻烦您验收一下，有问题随时@医小修～`。Webhook 必须原生提及；无路由正常跳过，个人通知独立。个人卡片移除渠道来源，已受理标题为“工程师正在处理你的工单”。
