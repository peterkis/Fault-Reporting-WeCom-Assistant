# 医小修 H5 V2：多媒体报修与成员服务

返回 [接口导航](../README.md) · [完整 HTTP 索引](../endpoint-index.md) · [原成员自助合同](self-service.md)

本页记录 [ADR-0035](../../../adr/0035_yixiaoxiu_h5_multimedia_and_member_service.md) 的本地实现。新增运行开关默认 `false`；本地实现、模拟 Provider 和隔离数据库验证不代表企业微信实机、真实收件、现场写库、部署或 Gate 批准。启用条件及角色环境见 [运行手册](../../runbooks/human-workbench-runtime.md#h5-v2-与多媒体显式启用)。

## 宿主、认证和协商

| 宿主标识 | 实际装配 | 边界 |
| --- | --- | --- |
| M | `createYxxSelfServiceExtension` 的 `MEMBER_SELF_SERVICE`；显式传入 `h5` 选项 | 沿原成员 HTTP/OAuth 宿主，不自行启动 Gateway、Sender 或媒体 Worker |
| F | `FULL_SERVICE_LOOP` 中的 P2-016 成员扩展；`createP2016Runtime` 显式传入 `yxxH5`，将同一 `h5Runtime` 注入成员自助 | F 是 W 内的成员装配标签，不是第二个监听服务；human-v1 App 使用此组合 |
| W | 同一 P2-016 App 的工作人员 HTTP 扩展 | 工作人员 Cookie／Bearer、当前 Workbench READ 和原对象授权；不能用成员 Cookie 替代 |

本页成员 API 的宿主均为 **M / F**。OAuth-only 与 `MEMBER_TICKET_READONLY` 不因 H5 构建产物存在就获得这些能力。使用同源 `__Host-wecom_session`；成员、企业、应用、原 Web Request 绑定和留存范围由服务端核验，浏览器不得提交人员 ID 来声明报修人身份。W 的四项材料／公开进度接口见 [管理端网页报修资料](../workbench/web-reports.md)。

前台恢复与温导航沿 [ADR-0037](../../../adr/0037_h5_session_resume_and_navigation.md)：新版 H5 显式 8 小时空闲／24 小时绝对会话期，entry 完整终检后才续期；本地会话失效时单次静默 OAuth 返回当前页面，403 保持权限拒绝。Hash 导航在 30 秒内只复用同范围／组织修订且未失效的完整内存缓存，最多 8 条访问戳；前台恢复、手动刷新和写后同步仍强制 entry，不重刷历史分页链。

复用的 `GET /api/yixiaoxiu/bootstrap`、`GET /api/yixiaoxiu/my-reports`、`GET /api/yixiaoxiu/requests/{requestRef}` 和 `POST /api/yixiaoxiu/requests` 通过 `Accept: application/vnd.yixiaoxiu.v2+json` 协商 V2。JSON 写入仍使用 `Content-Type: application/json`；未协商时继续原闭合 V1 合同。新增路径由 H5 handler 条件挂载，不是原 V1 的隐式字段扩张。

读请求拒绝 cross-site、错误 Origin 和请求体。写请求须精确 Host／Origin、当前 `X-CSRF-Token`，并在依赖等待后及提交前再次核验。新建、催单、评价和媒体写入还须原成员 `write_flag`、`YIXIAOXIU_SELF_SERVICE_ENABLED`、`YIXIAOXIU_MY_REPORTS_ENABLED` 同时允许；Header `Idempotency-Key` 精确对应本次 `client_command_id`。签名接口只签当前获权页面，不创建业务命令，无 `client_command_id` 字段。

## 复用的 V2 读取和报修

| METHOD + PATH | 输入与输出 |
| --- | --- |
| `GET /api/yixiaoxiu/bootstrap` | 无 query。保留原认证、CSRF、`recovery_scope` 与能力字段；新增 `h5: H5BootstrapExtension`，含人员资料、科室读取能力、媒体／催单／评价能力、`sdk`、支持电话和材料上限 |
| `GET /api/yixiaoxiu/my-reports` | 可选 `source`（WEB／BOT）、`search`（最多 100 字符）、`status`（OPEN／ACTIVE／COMPLETED）、`limit`（默认 20，1–50）、`cursor`。先限定本人获权记录，再筛选和分页，返回原 `items/next_cursor`；改变条件后丢弃旧游标 |
| `GET /api/yixiaoxiu/requests/{requestRef}` | 无 query；`requestRef` 是 32 位不透明引用。200 的原详情增加 `h5: H5RequestExtension`，含 Ticket 版本、意图、媒体、当前处理人、公开进度、催单和评价上下文。支持 `If-None-Match`／304，304 无 JSON 正文 |
| `POST /api/yixiaoxiu/requests` | 闭合 `H5RequestInput`，最多 16 KiB；首次 202、同 UUID 同正文重放 200。返回 `{ok,replayed,receipt,location}`；202 表示持久受理，不表示处理或外部通知完成 |

新报修的全部字段都须提供：`schema_version:2`、UUID `client_command_id`、`intent:FAULT|CONTACT_REQUEST`、`description:string|null`、`location:{text:string|null,unknown:boolean}`、`media_refs:UUID[]`。文字最多 4000 字符；位置最多 200 字符，未填写时使用 `text:null,unknown:true`。媒体引用最多 8 个且不重复。`FAULT` 至少有文字或一个已上传材料；`CONTACT_REQUEST` 可以没有文字和材料。

```json
{"schema_version":2,"client_command_id":"bce38e5a-ea9f-43f8-ae27-622d331653ca","intent":"FAULT","description":"打印机显示离线","location":{"text":null,"unknown":true},"media_refs":[]}
```

报修沿原 Web Request → Intake → Unified Ticket Core 受理编排，不伪造 Bot Inbox、Message 或 Conversation Session。材料在原受理事务中绑定，不接受他人的媒体引用。明确报修和需要联系的意图不等待转文字、人员补全或 AI 分类。

`h5.profile` 的姓名、电话、头像和部门来自已核验目录投影，缺失保留 `null`。Worker 只有在注入既有 Directory Port 和 `localOnly` 当前成员资格核验时才尝试补全；缺少映射、Provider 不可用或不能证明身份对应时保持待补／`DEFERRED`，不按姓名、相似 ID 或电话猜测。补全失败不撤销已受理工单，不扩大科室共享权限，也不新建全员目录同步。

## 科室、催单和评价

| METHOD + PATH | 合同 |
| --- | --- |
| `GET /api/yixiaoxiu/department-reports` | 可选 `search/status/limit/cursor`，规则同本人列表，无 `source`。返回 `H5DepartmentPage`：`items,next_cursor,total,active_count`。仅使用当前有效、快照未过期的已核验组织关系；返回前再次核对关系 |
| `POST /api/yixiaoxiu/requests/{requestRef}/urge` | 无 query；闭合 `{schema_version:1,client_command_id,expected_ticket_version}`。`If-Match` 必须为带双引号的 Ticket 数字版本，如 `"6"`。成功 200 返回 `H5LifecycleResult` |
| `POST /api/yixiaoxiu/requests/{requestRef}/evaluation` | 无 query；在催单字段基础上增加当前详情给出的 `completed_round_ref`、整数 `rating:1..5`、`comment:string|null`（最多 200 字符）。同样要求原 UUID／`If-Match`；成功 200 |
| `GET /api/yixiaoxiu/requests/{requestRef}/member-commands/{clientCommandId}` | 必需且唯一 query `purpose`，取 URGE／EVALUATION。按原本人、请求、UUID 和用途只读核对，返回 `H5LifecycleReceipt` 的 `UNKNOWN` 或 `COMMITTED`；不要求新写仍开启 |

科室投影只含工单号、服务类别、状态、创建时间和工作人员明确公开的进度／预计时间。不含原报修正文、人员电话、媒体或可绕开本人权限的详情引用。没有可靠组织关系时返回权限拒绝，不能把空列表解释为“科室没有故障”。

催单只追加本轮事实，同一工单每 10 分钟可新增一次；不改变优先级、工单状态或处理责任。管理端通过原获权投影和站内提醒消费，本期不增加企业微信主动催单消息。评价绑定实际工作人员完工轮次，每轮一次；不会再次关闭 Ticket。仍未解决继续使用原 [本人反馈／同单重开](web-feedback-design.md) 接口，不用评价接口改状态。

## 本人展示资料

`GET /api/yixiaoxiu/h5/profile` 沿 [ADR-0039](../../../adr/0039_h5_member_display_profile.md) 在 H5 显式装配及当前成员 READ 下启用；无 query、无正文，拒绝跨站、错误 Host／Origin。200 为闭合 `H5DisplayProfile`：`{schema_version:1,recovery_scope,profile:{name,department}}`，两个显示值为字符串或 null。仅当前 HTTP 核验的本人可读，`no-store`，不返回原始成员／部门 ID、凭据、电话、头像或 Provider 原始错误。

本次官方 `user/get` 核验及最多一次 `department/get` 共用原 BASE 单槽、32 项队列和含排队 5 秒预算；原 entry 不等待此网络读取。优先成员主部门，主部门未返回时取其部门列表首项；缺少或无法读取部门只影响显示，成员资格拒绝与暂不可用仍分别为 401／403 和 503。返回前复核当前 Cookie、会话、成员恢复范围；客户端取消传播到实际网络工作，底层未 settle 不提前释放槽。

Home／资料弹窗仅在已确认 entry 后补缺少的显示字段，使用独立成员与组织修订缓存键，30 秒新鲜度、2 分钟非活动回收。短时导航复用结果，过期后重新挂载或前台统一复核后重新读取；旧认证代次或取消的响应不能回填。展示部门不授予科室工单 READ，不改变 `can_view_department`、组织修订、原身份 HMAC 或历史资料；原本地目录和权限终检保持。

## 签名和媒体

以下路径均在原成员范围内操作。媒体引用是 UUID，无法仅凭引用读取文件；原始文件名、存储路径、令牌、ticket 和服务器素材 ID 不进入成员材料 DTO。

| METHOD + PATH | 输入、状态与输出 |
| --- | --- |
| `POST /api/yixiaoxiu/js-sdk/signature` | JSON 最多 2 KiB，闭合 `{url,kind}`，`kind` 为 CORP／AGENT，当前成员写能力与 CSRF；仅允许同源 H5 URL。200 返回 **`{corpId,agentId,timestamp,nonceStr,signature}`**，时间戳为秒，不返回凭据 |
| `POST /api/yixiaoxiu/media/uploads` | JSON 最多 2 KiB；闭合 `H5MediaReservationInput`：`schema_version:1,client_command_id,kind,mime_type,byte_size,duration_ms`。后两项可为 `null`，图片时长必须为 `null`。首次 201／原 UUID 重放 200，返回 `H5MediaReservation` 的 `media_ref,kind,status,expires_epoch_ms,replayed` |
| `PUT /api/yixiaoxiu/media/uploads/{mediaRef}/content` | 原始二进制请求体，无 query；当前 CSRF／`Idempotency-Key`，按预留的类别与 MIME 检验实际容器和大小。成功 200 返回 `H5MediaMetadata`；READY／BOUND 的同引用不被新内容替换 |
| `POST /api/yixiaoxiu/media/uploads/{mediaRef}/wecom` | JSON 最多 1 KiB，闭合 `{server_id}`；当前 CSRF／`Idempotency-Key`。服务端从企业微信获取临时素材并验证后私有保存，200 返回 `H5MediaMetadata`；浏览器不直接获取 access token |
| `DELETE /api/yixiaoxiu/media/uploads/{mediaRef}` | 无 query、无正文，当前 CSRF／`Idempotency-Key`；取消未绑定材料并清理该材料私有对象，200 `{ok:true}`。已绑定或正在写入时 409，不删除工单材料 |
| `GET /api/yixiaoxiu/requests/{requestRef}/media/{mediaRef}` | 唯一可选 query `variant`，取 PLAYABLE／ORIGINAL，默认 `PLAYABLE`；当前本人 READ、原 Request／Intake 绑定和留存，每个输出块前再次核验。200 为精确 MIME／大小的二进制流，`no-store/nosniff`；原件使用 attachment |

没有挂载 `GET /media/uploads/{mediaRef}`，也没有独立的“上传完成”HTTP 路径；内部 reservation／材料绑定方法不是 REST 接口。上传结果未知时，保留原预留 UUID 和闭合输入，以同 UUID 重新取得原预留结果；新报修、催单、评价的未知结果使用各自原用途回执，不能换 UUID 盲重试。

每单最多语音 1 段／60 秒／5 MiB、图片 6 张／每张 10 MiB、视频 1 段／60 秒／20 MiB，总材料 40 MiB。每成员最多 16 个未绑定预留；上传串行，服务端媒体操作单并发、60 秒截止。图片支持 JPEG／PNG／WebP；声音支持 AMR／WAV／MP4／WebM／Ogg／MPEG；视频支持 MP4／WebM／QuickTime，按实际容器验证，不因文件扩展名放行。未声明 HEIC 或任意文件支持。

原件以 AES-256-GCM 存入独立私有根目录。图片直接可显示；语音、视频先保存原件并返回 `PENDING`，Worker 在原有限周期内单并发生成 WAV／H.264 MP4 播放副本。失败标为 `UNAVAILABLE`，原件和报修仍保留；`PLAYABLE` 不可用时明确 503，不将 AMR／Speex 原件假装成浏览器通用音频。

未绑定材料最多保留 24 小时。绑定后的截止取原 Web Request、Submission、Intake 留存约束的最早值；旧默认报修留存仍为 30 天，绑定不能延长原截止。Worker 到期清理每次最多 16 项，删除过期原件／副本的密文并记录 `purged`，保留历史行。关闭新写、转码失败或退出页面不会提前删除已绑定原件；浏览器不持久保存敏感草稿或媒体。

## 错误、恢复和公开资源

错误外壳为 `{"error":{"code":"YXX_...","retryable":false}}`。401 重新认证；可信 403 清受保护内容和 Blob URL；404 不泄漏他人记录；409 表示版本、冷却时间或幂等内容冲突，先重读；413／415／422 分别表示大小、类型或材料格式问题；429 为容量；503 为依赖暂不可用，不等同成员撤权。

写操作关闭自动重试。超时、断网或无法核验的响应保留 **UNKNOWN + 原 UUID + 原正文**。创建沿 `GET /api/yixiaoxiu/commands/{clientCommandId}`；催单／评价沿上述 `member-commands`，仍未解决沿原反馈回执。`UNKNOWN` 不能解释为未执行；仅凭过期页面版本或一次 Provider 失败不能换身份、改用途或重发新命令。

静态资源使用 `GET /wecom/yixiaoxiu/assets/{buildAsset}`，只读取本次 Vite manifest 可达的 JS、CSS、WOFF2、PNG、JPEG、WebP、SVG，保留同源 CSP。设计原件、`src/dev`、preview、未声明资源、manifest／inventory、路径越界和符号链接均不作为公共资源；缺少制品明确不可用，不回退源码。该静态路径不授予业务读取权。构建使用原根制品管线，H5 产物位于 `runtime/h5`。

## 企业微信官方依据与验证范围

2026-10-20 已读取以下官方页面实际正文；仅为公开文档核验，没有调用真实企业 API：

- [常见问题 - FAQ](https://developer.work.weixin.qq.com/document/path/90457) 的 UA 示例包含 `Language/zh`。本项目优先读 UA `Language/…`，缺失时用浏览器语言，中文统一 `zh-CN`、其他语言为 `en`；这是 ADR-0035 的产品归一规则，不是新的身份来源。
- [深色模式适配指南](https://developer.work.weixin.qq.com/document/path/94601) 给出 `prefers-color-scheme` 与 `ColorScheme/Dark`；[官方色值表](https://developer.work.weixin.qq.com/document/path/94594) 提供对应设计色。页面优先使用显式 `ColorScheme/Dark|Light`，缺失时跟随系统媒体偏好，首屏及恢复可见时更新。
- [JS-SDK 签名算法](https://developer.work.weixin.qq.com/document/path/90506) 要求服务端签名、去掉 URL 的 `#` 部分、按规定参数顺序 SHA-1，且企业／应用 ticket 分别缓存。签名只返回本页所列公开字段。
- [获取临时素材](https://developer.work.weixin.qq.com/document/path/90254) 与 [获取高清语音素材](https://developer.work.weixin.qq.com/document/path/90255) 是不同获取路径。本期走普通素材／AMR 支路并受控转码；高清接口返回 Speex，不能据此宣称已完成高清语音解码或鸿蒙支持。

此前提到的 [90526](https://developer.work.weixin.qq.com/document/path/90526) 实际标题为“调起电子发票”，不作为语言或主题依据。本期不包含电子发票能力。企业微信 iOS／Android 的真实录音、相机、主题和语言效果须按实际设备记录；未执行项保留 `NOT_RUN`。
