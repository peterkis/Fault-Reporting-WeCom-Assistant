# 验收场景清单

## 核心链路

- [ ] 群内 @ 文字生成一张工单；
- [ ] 重放同一 msg_id 不重复建单；
- [ ] 数据库提交前不回复；
- [ ] AI 停止后正常建单；
- [ ] Pilot Ticket Core 超时后消息不丢，可补建；
- [ ] 状态和 Outbox 同事务；
- [ ] 接单、开始处理语义分开；
- [ ] 单聊收到待补充和解决确认；
- [ ] “仍未恢复”可重开；
- [ ] 自动关闭与用户确认分开统计。

## 媒体

- [ ] 图片下载和解密；
- [ ] 私有存储；
- [ ] 纯图片先建单；
- [ ] OCR 超时不阻塞；
- [ ] 患者信息不出现在普通日志；
- [ ] 外部不可见附件不能被申报人访问。

## Incident

- [ ] 三个同错误报告形成候选；
- [ ] HIS登录和HIS打印不合并；
- [ ] 关联后保留三个 Intake；
- [ ] 解除关联可恢复；
- [ ] 100订阅人通知不重复。

## 企业微信

- [ ] 24小时稳定连接；
- [ ] 断网自动重连；
- [ ] 主动单聊；
- [ ] 主动群消息；
- [ ] 卡片按钮；
- [ ] 过期和重复按钮安全处理。

## 安全

- [ ] Bot Secret 扫描；
- [ ] 越权工单访问；
- [ ] 越权附件访问；
- [ ] 恶意文件；
- [ ] Prompt 注入；
- [ ] 日志敏感数据扫描；
- [ ] 留存删除任务。
