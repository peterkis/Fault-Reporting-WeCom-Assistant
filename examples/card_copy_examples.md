# 企业微信卡片和文案示例

## 1. 首次确认

```text
问题已收到并生成工单 IT-20260820-0013
当前状态：等待受理
问题摘要：HIS 登录异常

[查看工单] [补充信息]
```

禁止：

```text
收到，正在处理
```

除非工单已经进入 `IN_PROGRESS`。

## 2. 已接单

```text
工单 IT-20260820-0013 已由信息科王工受理。
```

## 3. 开始处理

```text
工单 IT-20260820-0013 已开始处理。
```

## 4. 待补充

```text
工单 IT-20260820-0013 需要您补充：
- 终端编号；
- 是否只有该终端出现。

[补充信息] [查看详情]
```

## 5. 解决确认

```text
工单 IT-20260820-0013 已处理完成
处理结果：已重新同步账号权限

[已恢复] [仍未恢复] [查看详情]
```

## 6. 公共故障确认

```text
已确认多个科室出现 HIS 登录异常。
您的反馈已关联公共事件 INC-20260820-003，无需重复报修。
信息科正在统一处置。
```

## 7. 公共故障进展

```text
公共事件 INC-20260820-003
当前进展：已定位统一认证服务异常，正在恢复。
```

## 8. Tickets 暂时不可用

```text
问题已可靠记录，工单正在生成。
系统恢复后将自动发送正式工单号。
```

不得生成虚假工单号。
